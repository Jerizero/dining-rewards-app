# Dining Rewards Arbitrage (NYC)

Web app for finding the highest-value credit card and rewards stack across NYC restaurants participating in **inKind**, **Seated**, **Bilt Dining**, and **Blackbird**.

## Development

```bash
npm install
npm run dev       # http://localhost:3030
npm run build     # Type-check + Vite production bundle
npm test          # Calculator, hours, distance & storage tests
```
